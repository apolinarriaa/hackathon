## Як запустити

1. Завантажте проєкт на свій комп'ютер.
2. Відкрийте термінал у папці проєкту.
3. Встановіть потрібні бібліотеки командою `pip install -r requirements.txt`
4. Запустіть застосунок командою `streamlit run app.py`
5. Застосунок відкриється в браузері.

**Наш проєкт - гра-симулятор прогнозування курсу валют на відкритих даних НБУ.**

Гравець отримує стартовий баланс і грає 7, 14 або 30 днів. Щодня він бачить поточний курс євро або долара і робить ставку: курс завтра зросте чи ні. Майбутні курси приховані, тож вгадати наперед неможливо.

Якщо прогноз правильний, гравець отримує 10% від ставки, якщо ні - втрачає 10%. Поставити більше, ніж є на балансі, або нуль не можна.

(показати: зробити ставку → перейти на наступний день → баланс змінився)

На графіках видно, як змінювався курс за попередні дні, а після гри - історія всіх ставок.

Дані ми взяли з відкритих історичних курсів Національного банку України.
